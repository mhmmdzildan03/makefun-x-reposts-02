An entry for make.fun's "Get the most reposts and likes on make.fun's newest X posts" bounty. The entry is a set of up to 15 posts on X from one public account, each a quote of, or a direct reply to, a different one of @makefunai's newest posts, each carrying make.fun and the entrant's play code in its own words. Their addresses are listed in `POSTS.json`; `main.ts` validates that list (at most 15 well-formed X status addresses, no duplicates, all from one account) and prints a summary of the entry.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
